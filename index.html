개인정보처리방침

SnapStock (찰칵재고)

시행일: 2026년 6월 7일

SnapStock(이하 "앱")은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 본 개인정보처리방침은 앱이 수집하는 정보의 종류, 이용 목적, 보관 기간 및 이용자의 권리에 대해 안내합니다.

1. 수집하는 개인정보 항목

1-1. 필수 수집 항목

  • Google 계정 인증 정보: 이메일 주소, 표시 이름, 프로필 사진 URL (Firebase Authentication을 통한 로그인 시)

1-2. 서비스 이용 과정에서 자동 수집되는 정보

  • 앱 충돌 및 오류 정보: 기기 모델, OS 버전, 앱 버전, 충돌 로그 (Firebase Crashlytics)

1-3. 이용자가 직접 입력하는 정보

  • 식재료 이름, 수량, 유통기한, 카테고리 등 재고 관리 데이터
  • 카메라로 촬영한 영수증 이미지 (AI 분석 후 텍스트만 저장, 원본 이미지는 서버에 영구 저장되지 않음)

2. 개인정보의 이용 목적

수집된 정보는 다음 목적으로만 사용됩니다.

  • 회원 식별 및 로그인 기능 제공
  • 식재료 재고 관리 서비스 제공 (등록, 수정, 삭제, 동기화)
  • 가족/룸메이트 간 냉장고 공유 기능
  • AI 기반 레시피 추천 (Google Gemini API 활용)
  • 영수증 OCR 스캔을 통한 식재료 자동 등록
  • 유통기한 알림 서비스
  • 앱 안정성 개선 및 오류 수정 (충돌 분석)

3. 개인정보의 보관 및 파기

  • 재고 데이터는 Firebase Firestore에 저장되며, 이용자가 계정을 삭제하거나 데이터를 직접 삭제할 때까지 보관됩니다.
  • 충돌 로그는 Firebase Crashlytics에 90일간 보관 후 자동 삭제됩니다.
  • 이용자가 회원 탈퇴를 요청할 경우, 관련 데이터는 요청일로부터 30일 이내에 파기합니다.

4. 개인정보의 제3자 제공

앱은 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만 다음의 경우는 예외로 합니다.

  • 이용자가 사전에 동의한 경우
  • 법령에 의해 요구되는 경우

5. 제3자 서비스 (위탁 처리)

앱은 서비스 제공을 위해 다음 제3자 서비스를 이용합니다.

  • Firebase Authentication (Google LLC): 사용자 인증
  • Cloud Firestore (Google LLC): 재고 데이터 저장 및 동기화
  • Firebase Crashlytics (Google LLC): 앱 충돌 분석
  • Google Gemini API (Google LLC): AI 레시피 추천, 영수증 OCR 처리

각 서비스의 개인정보처리방침은 해당 서비스 제공자의 정책을 따릅니다.

6. 이용자의 권리

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

  • 개인정보 열람, 수정, 삭제 요청
  • 회원 탈퇴 및 데이터 삭제 요청
  • 앱 내 설정에서 직접 데이터 관리 가능

7. 카메라 권한

앱은 영수증 OCR 스캔 및 바코드 스캔을 위해 카메라 접근 권한을 요청합니다. 촬영된 이미지는 AI 분석 목적으로만 사용되며, 서버에 영구 저장되지 않습니다.

8. 아동의 개인정보 보호

앱은 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다. 만 14세 미만 아동이 개인정보를 제공한 사실을 알게 된 경우, 해당 정보를 즉시 삭제합니다.

9. 개인정보처리방침의 변경

본 방침이 변경되는 경우, 변경 사항은 이 페이지를 통해 공지되며 변경 시행일 이전에 고지합니다.
